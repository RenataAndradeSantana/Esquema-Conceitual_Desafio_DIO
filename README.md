Desafios DIO - Heineken - Esquema Conceitual Oficina Mecânica 
📝 Descrição
Este repositório contém os desafios proposto pelo curso Heineken - Inteligência Artificial Aplicada a Dados com Copilot oferecido pelo DIO.
Descrição do Projeto

Este projeto consiste no esquema conceitual para um sistema de controle e gerenciamento de execução de ordens de serviço em uma oficina mecânica. O sistema permitirá o registro de clientes, veículos, mecânicos e ordens de serviço, garantindo o acompanhamento detalhado dos serviços prestados.
